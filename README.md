# Personal fitness dashboard

Buildless static website. Open index.html or serve this directory with a static server.

nutrition.html contains the 2026-11-20 lunch record and four original photographs. All nutrition totals are estimates; the soup calorie value was supplied by the user.

The repository was empty when inspected; no existing Hevy implementation was available. The homepage reserves a training section without inventing training data.

Deployment: in GitHub Settings → Pages choose GitHub Actions. Push main to run the included Pages workflow. Expected URL after successful deployment: https://orafrank.github.io/personal-fitness-dashboard/
